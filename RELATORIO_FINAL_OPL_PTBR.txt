7. GSKIT

STATUS: BLOQUEANTE

O erro conhecido gsKit.h: No such file or directory foi identificado.
O gsKit é um componente separado do libgs que fornece a interface C
para o Graphics Synthesizer da PS2.

O que foi feito:
- libgs já está disponível em /home/bruno/ps2dev/ps2sdk/ee/libgs/
- Foram criados stubs parciais em /home/bruno/OPL-Refactored/gsKit/
- Os stubs permitiram compilar alguns arquivos do frontend
- No entanto, a grande maioria dos arquivos do frontend ainda falha
devido à complexidade da interface GS e à falta de definições completas

Para resolver completamente:
1. Instalar/construir o gsKit properamente
2. Ou obter os headers e bibliotecas gsKit de outra fonte
3. Os stubs atuais são insuficientes para um build completo

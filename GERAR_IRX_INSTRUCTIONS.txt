=================================================================
INSTRUÇÕES PARA GERAR MÓDULOS IOP (.IRX)
=================================================================

ETAPA 1: ACESSAR O DIRETÓRIO
--------------------------------
Digite no terminal:
  cd /home/bruno/OPL-Refactored

ETAPA 2: LIMPAR BUILD ANTERIOR
--------------------------------
Digite e ENTER:
  make clean

ETAPA 3: COMPILAR MÓDULOS IOP
--------------------------------
Digite e ENTER:
  PATH="/usr/local/ps2dev/ee/bin:/usr/local/ps2dev/bin:$PATH" make -e -C modules/iopcore all

Isso vai gerar vários arquivos .irx na pasta modules/iopcore/

ETAPA 4: COPIAR PARA O RELEASE
--------------------------------
Digite e ENTER:
  mkdir -p /home/bruno/OPL-PS2-RELEASE/IOP
  cp modules/iopcore/*.irx /home/bruno/OPL-PS2-RELEASE/IOP/

ETAPA 5: VERIFICAR
--------------------------------
Digite e ENTER:
  ls -lh /home/bruno/OPL-PS2-RELEASE/IOP/

Deve aparecer vários arquivos .irx com tamanhos diferentes

ETAPA 6: COPIAR PARA O PEN-DRIVE DO PS2
--------------------------------
1. Copie a pasta IOP/ do release para /PS2/IRX/ no seu pen-drive/HDD
2. Certifique-se também de ter o OPL.ELF em /PS2/OPL.ELF
3. No uLaunchELF, navegue até o OPL e execute

=================================================================
COMANDOS ÚNICOS (TUDO Junto)
--------------------------------
Se quiser fazer tudo de uma vez, digite:

  cd /home/bruno/OPL-Refactored && make clean && PATH="/usr/local/ps2dev/ee/bin:/usr/local/ps2dev/bin:$PATH" make -e -C modules/iopcore all && mkdir -p /home/bruno/OPL-PS2-RELEASE/IOP && cp modules/iopcore/*.irx /home/bruno/OPL-PS2-RELEASE/IOP/ && ls -lh /home/bruno/OPL-PS2-RELEASE/IOP/

================================================================
DUVIDAS COMUNS
=================================================================

Q: Apareceu erro 'iopfixup: Arquivo ou diretório inexistente'
R: Verifique se /usr/local/ps2dev/ps2sdk/bin/iopfixup existe

Q: Apareceu erro 'have you installed the static version'
R: Alguns avisos estão OK, o build pode completar mesmo assim

Q: IRXs não funcionam no PS2
R: Certifique-se de copiar TODOS os IRXs necessários (cdvdman, usbd, smap, netman, etc.)
